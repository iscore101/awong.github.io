# Anthony Wong's website

This website uses the formatting and code structure of
[Devan Shah's website](https://dshah.io/) as a reference. The site
content, images, and documents belong to Anthony Wong.

## Local preview

```bash
export PATH="/opt/homebrew/opt/ruby@3.3/bin:$PATH"
bundle install
bundle exec jekyll serve
```

Then open `http://127.0.0.1:4000`.
